# Требования к безопасности интеграции сервисов "Умный дом" для PropDevelopment

## 1. Требования к безопасности

### 1.1. Защита данных

- [ ] **Шифрование данных**: Все передаваемые данные (биометрия, номера авто) должны шифроваться (TLS 1.2+)
- [ ] **Хранение чувствительных данных**:
  - Биометрические шаблоны хранятся только в зашифрованном виде
  - Номера автомобилей токенизируются
- [ ] **Сертификация**: Партнер должен предоставить сертификат соответствия ФСТЭК/ФСБ (для биометрии)

### 1.2. Контроль доступа

- [ ] **Верификация прав**:
  - Для домофона: проверка права доступа в жилой комплекс
  - Для шлагбаума: проверка автомобиля в white-листе
- [ ] **Журналирование**: Логирование всех событий доступа с привязкой к учетной записи

### 1.3. Устойчивость к атакам

- [ ] **Защита от спуфинга**:
  - Для биометрии: liveness detection
  - Для номеров: проверка через несколько кадров
- [ ] **Rate-limiting**: Ограничение 5 запросов/минуту на устройство

## 2. Протоколы аутентификации и авторизации

### 2.1. Аутентификация

Аутентификация и авторизация пользователя остаётся на стороне мобильного приложения. Команды на управление устройствами будут отправляться сервисом tenant-core-app.

### 2.2. Авторизация

- [ ] **Ролевая модель**:
  - Собственники: полный доступ к своим устройствам
  - Арендаторы: временный доступ (через отдельный scope)
  - УК: доступ к журналам своих домов
